# Сервис заявок на ремонт техники

Учебный проект по ПМ.05. Сделан на Flask и MySQL.

Пользователь может зарегистрироватся и оставить заявку на ремонт. Администратор может просматривать и редактировать заявки, добавлять их и удалять их, искать и фильтровать по статусу. 


## Запуск

1. Установить зависимости: `pip install -r requirements.txt`
2. Импортировать `sql/schema.sql` в MySQL.
3. Создать файл `.env` с параметрами `SECRET_KEY`, `DB_USER`, `DB_PASSWORD`, `DB_HOST`, `DB_PORT`, `DB_NAME`.
4. Запустить: `python app.py`
